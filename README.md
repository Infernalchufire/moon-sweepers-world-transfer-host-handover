## 🛠️ Troubleshooting / Fix Workflow

1. Ask the current host to exit the game cleanly and finish saving.
2. Find the world’s local save location using the game installation and backup folder reference; preserve the full corresponding folder.
3. Make two dated copies: one untouched archive and one working transfer copy.
4. Confirm the receiving player is running the same version as the origin world (1.0.4 saves cannot open older versions).
5. Before replacing local save data, review Steam Cloud synchronization and retain an untouched copy on each computer.
6. Transfer only the duplicate files using your normal file-sharing method; do not overwrite the original world on the first machine.
7. Test the imported world offline or with a small crew; verify world ownership, progression and host/client behavior before relying on it.

## ❓ FAQ

**Does Moon Sweepers have an official one-click host transfer?**  
The published 1.0.4 patch notes do not establish one; this is a manual transfer planning guide.

**Can a 1.0.4 save load in 1.0.3?**  
No. The developer explicitly warns that newer saves are incompatible with older builds.

**Will an imported world keep the same host permissions?**  
Host ownership behavior should be tested in-game; do not assume a file copy preserves every online permission.
